# pvillavi.github.io

Personal site and editorial archive for Pedro Villavicencio.

## Structure

- `src/pages/index.astro`: existing professional homepage, preserved as the root page.
- `src/pages/es/articulos/`: Spanish editorial archive and articles.
- `src/pages/en/articles/`: English editorial archive and articles.
- `src/pages/es/proyectos/` and `src/pages/en/projects/`: project pages.
- `src/layouts/`: shared layouts for archive and article pages.
- `public/assets/`: images served as static assets.

## Local development

```bash
npm install
npm run dev
```

The site is built as a static Astro site and published through GitHub Pages.
